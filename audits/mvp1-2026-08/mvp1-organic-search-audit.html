The verdict

summary

Four months of SEO work have coincided with organic search performance falling by roughly half. The site itself is technically sound, so the problem is not the website. The problem is that almost none of the work billed against it was aimed at, or capable of, moving commercial rankings.

The one number that settles it

Strip out people searching for mvp1, mvp1 ventures and mvp ventures, the people who already know the company, and what remains is the traffic SEO is actually paid to create. That number is 0 to 1 clicks per month, and it has not moved since March. Of the 17 commercial keywords the agency mapped across four months, one has ever registered a single impression: private ai infrastructure, which drew 9 impressions and no clicks in May, then disappeared.

Everything else in this report explains why.

Fix today

security

Live account credentials are sitting in a publicly-readable Drive folder

The folder shared for this review is set to "anyone with the link can view". At least four files inside it contain the plaintext password for mvpausqld@gmail.com, the Google account that controls the Google Business Profile, along with the recovery email and recovery phone number.

Affected files: Month 1 / …_CUSTOM_Final_Report.xls, Month 3 / …GEO_SEO_Month_2_CUSTOM_Final_Report.xls (both in a "Package Reports" tab), Month 3 / …Australia_Claim_and_Verification_Report.pdf, and the "CP" content-posting tabs, which additionally expose the same password reused for Medium and Tumblr accounts. A second, different password for the same Gmail address appears in the Australia claim report.

Do this now: change the Google account password and revoke active sessions; rotate the Medium and Tumblr passwords; change the recovery phone and email; turn the Drive folder's link sharing off; then review Business Profile edit history for changes you did not authorise. Password reuse across the Google account and third-party publishing accounts means one leak compromises all of them.

The engagement's own benchmark report covers 16 March – 14 April, so March and April are the honest "before". Every organic metric has fallen since, and the decline is steepest in the months with the most billed activity.

BrandedNon-branded

Read this before drawing conclusions about cause

Branded impressions fell as hard as non-branded ones, from 2,927 in April to 1,134 in August. Rankings for those brand terms held steady around position 5–6 throughout. That pattern means fewer people searched for MVP1, not that the site lost brand rankings. Part of this decline is falling brand demand, which is a marketing problem rather than an SEO execution failure, and it would be unfair to lay all of it at the agency's door. What the agency is accountable for is the non-branded line, and that line never left zero.

The rising CTR is not good news

Click-through rate climbed from 4.18% to 5.30% between April and August, and a report could fairly present that as an improvement. It is not. CTR rose because impressions fell faster than clicks. The site stopped appearing for the wide, low-intent queries that generate impressions without clicks. A shrinking denominator lifted the ratio. Judge this engagement on clicks and non-branded reach, not CTR.

Technical audit

53 pages crawled

Independent of anything the agency claimed. The headline is genuinely positive: this is a well-built, fast, clean site. The issues below are real but mostly modest. None of them explains the traffic decline on its own.

Healthy

  • All 53 sitemap URLs return HTTP 200, no broken pages, no redirect chains
  • Every page has a correct self-referencing canonical
  • No stray noindex; every page has exactly one H1
  • Fast: 0.40s average server response, 19KB average HTML
  • Strong security headers: HSTS with preload, a real CSP, nosniff, X-Frame-Options
  • No thin content, every page clears 300 words
  • Viewport and lang set site-wide; all meta descriptions present
  • Legacy URLs from the site's rebuild redirect correctly with 308s

Needs work

  • /blog returns 404, the blog index is missing, and it drew 101 impressions
  • Four /news/ URLs are hard 404s, costing about 254 impressions
  • 17 of 53 pages carry no structured data, including /about-us, /contact and /overview
  • 20 of 42 homepage images have no alt text; 40 images site-wide lack width/height
  • 18 meta descriptions exceed 160 characters and will be truncated
  • 15 title tags exceed 60 characters; /faq and /careers are under-written at 19 and 23
  • /rates is orphaned: live, drew 236 impressions, absent from the sitemap
  • /blackvault-private-ai-infrastructure exports equity off-domain: 284 impressions redirect to blackvault.au

Two things worth knowing

47 of 53 pages earned zero organic clicks in August. Traffic is concentrated almost entirely on the homepage (92 clicks), with /overview and the GBP-tagged homepage URL taking most of the rest. The blog, the case studies, the service pages and the podcast episodes are collectively invisible in search, which is precisely what the keyword mapping was supposed to change.

The legacy WordPress host is still reachable. dev.mvp1.com.au blocks HTML requests via ModSecurity but still serves image files. Low risk, but it should be taken down or firewalled, and it is the source of the stale image paths in the ALT deliverable.

Method & limits

reproducibility

What was done

  • Search Console API, URL-prefix property, March–August 2026, dataState: all, by query, page, device and country
  • GA4 Data API, property 476568741, same window, by channel, device, source/medium, landing page and event
  • Full crawl of all 53 sitemap URLs: titles, meta, headings, canonicals, JSON-LD, images, links, response times
  • All 34 Drive deliverables downloaded and parsed: PDF, XLS, XLSX and DOCX
  • Live HTTP verification of 70 sampled PR links, 25 legacy URLs, and every agency-referenced URL

Known limits, read these

  • August is 30 days, not 31. Search Console had not published 31 August at the time of the pull.
  • Branded/non-branded is computed on visible queries only, 62–79% of clicks. Google withholds the rest. The direction is unambiguous; the exact split is approximate.
  • Only the URL-prefix property was readable. If a domain property exists, its numbers will be higher, and that may partly explain the benchmark gap.
  • Business Profile console was not accessible, so GBP figures are corroborated through GA4 rather than proven.
  • No Core Web Vitals field data. The configured API key is invalid and the PageSpeed quota was exhausted, so CrUX could not be read. Server response times here are measured, not field-sourced.
  • Backlink totals were not independently audited: no Ahrefs or Moz access. PR links were verified by direct HTTP fetch instead.

Verdict definitions. Verified: the claim is independently confirmed by live data. Partly verified: consistent with available data but not fully provable from the sources accessible here. Contradicted: the live site or raw data disproves the claim as written. Not delivered / Duplicate / Quality failure: the artefact exists but has no verifiable substance.
